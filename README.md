# 🔥 EsperanzaKonva Forge
### *By FlaskArchitect*

> **100% Free, Zero-Watermark, In-Canvas Rich Typography & Kinetic Motion Graphics Studio**

---

## 🚀 Overview

**EsperanzaKonva Forge** is a high-performance web-based motion graphics and typography suite built with TypeScript, Konva.js, and HTML5 Canvas. It allows creators to build cinematic video titles, curved typography, animated stickers, and atmospheric particle overlays—then export them as **lossless transparent WebM videos at 60 FPS** ready to drop directly into Adobe Premiere, DaVinci Resolve, CapCut, or OBS.

---

## ✨ Features

### 1. ✍️ Rich In-Canvas Typography Engine
- **Per-character and per-run styling**: Bold, italic, color, font size, stroke, and drop shadows.
- **Parametric Curved Text Arcs**: Real-time sine and circular text bending without vector distortion.
- **Multi-layer Text Boxes**: Full drag, resize, rotate, and aspect-ratio handles via custom Konva transformers.
- **Deep Alignment & Spacing**: Letter spacing, line height, paragraph spacing, and star lists (`★`).

### 2. 🌌 17 Procedural Atmospheric Scene Overlays (From Effects Studio)
Pure HTML5 2D canvas procedural particle and optical shaders running at 60 FPS:
- **✨ Golden Sparkles**: Twinkling 4-point gold stars with radiant shimmer.
- **🔮 Dreamy Bokeh**: Soft floating pastel depth-of-field orbs.
- **💖 Hearts & Embers**: Romantic floating hearts and warm glowing embers.
- **🌧️ Cinematic Rain**: Slanted high-velocity rainfall with ground ripple splashes.
- **❄️ Winter Snowfall**: Soft drifting snowflakes with horizontal wind drift.
- **🌌 Cosmic Dust**: Ambient floating dust motes with soft glow.
- **🔦 Volumetric Beams**: Sweeping searchlights and dramatic god rays.
- **🪐 Orbital Hologram**: Concentric rotating dashed rings and live quantum telemetry.
- **💎 Crystal Shield**: Pulsing radiant crystalline energy nodes.
- **🎯 Drone Recon Crosshair**: Tactical scanner reticles and corner HUD brackets.
- **☀️ Celestial Suns**: Solar anamorphic flares and satellite laser strikes.
- **📼 Retro VHS 1994**: 90s camcorder tracking jitter, flashing REC, and OSD running clock.
- **📺 CRT Scanlines**: Interlaced scanline raster grid with chromatic glitch twitch.
- **🌡️ Thermal Mode**: Infrared false-color thermal vision simulation.
- **📡 Broadcast HUD**: Live news lower-third ticker and viewfinder brackets.
- **🎬 Vignette**: Smooth feathered dark edge falloff.
- **🌐 Cyber Synthwave Grid**: 3D perspective floor wireframe grid with horizon vanishing point.

### 3. 🖼️ Transparent PNG & 60 FPS Animated GIF Studio
- **Multi-frame GIF playback**: Hardware-accelerated frame decoding at smooth 60 FPS.
- **Pre-rendered Vector Badges**: `LIVE`, `SUBSCRIBE`, `4K ULTRA HD`, and `VERIFIED`.
- **Animated Stickers**: Pulsing REC badges and rotating cyber reticles.
- **Desktop Drag-and-Drop**: Drop any transparent PNG or GIF directly onto the canvas.

### 4. 🎬 60 FPS Kinetic Video Recording
- **Transparent WebM Video**: Records animations with full alpha channel transparency.
- **Direct NLE Compatibility**: Drag exported `.webm` clips onto transparent video tracks in Premiere Pro, DaVinci Resolve, or CapCut.
- **Backdrop Modes**: Obsidian Dark Studio, Chroma Key Green Screen, or Alpha Grid.

### 5. 📄 JSON Document & Preset System
- Bidirectional project import/export.
- Independent Text Box Document format or Full Canvas Project format.
- Pre-packaged ready-to-render templates in `/examples/`.

## 🛠️ Quick Start

```bash
# Clone repository
git clone https://github.com/flaskarchitect/esperanzakonva-forge.git
cd esperanzakonva-forge

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

---

## 📦 Production Build

```bash
npm run build
```

The optimized static bundle is output to `dist/`.
